# AtomLearn 0.14.2 Release Notes

Status: stable candidate. Stable publication exists only after the signed `v0.14.2` tag workflow succeeds.

## Scope

AtomLearn 0.14.2 contains the complete 0.14 Phase 0–7 remediation: Evidence state safety, calibrated measurement, bounded self-evolution experiments, typed start orchestration, layout-preserving Document IR, semantic RAG, automatic exam and research workflows, qualified per-Atom adaptive review, and the unified daily queue. Full feature, compatibility, security, and limitation detail remains in the [0.14.0 feature notes](v0.14.0.md).

## Patch correction

The immutable `v0.14.1` tag passed the complete Windows/Linux Python 3.10–3.13 release matrix. Its final signed-manifest build then failed closed because the capability ledger correctly required the Phase 7 `review` smoke while `release-manifest-v2.schema.json` still admitted only the earlier capabilities.

Version 0.14.2 adds `review` to the schema and adds a repository contract proving that every `required_smoke` value in the capability ledger is accepted by the release schema. The `v0.14.1` tag remains unmoved and published no GitHub Release or stable asset.

## Release invariants

- Fixed 1/3/7/30 review scheduling remains the default and fallback.
- Adaptive-active review still requires a current benchmark and explicit learner opt-in.
- Self-evolution v2 capabilities retain their independent opt-ins and default-off boundaries.
- The stable release still requires the complete Windows/Linux Python 3.10–3.13 matrix, named HNSW gate, signed gate report, exact runtime matrix, Ed25519 signature, and immutable GitHub Release assets.
- The failed `v0.14.0` and `v0.14.1` attempts produced no stable manifest, Manager wheel, Core ZIP, runtime bundle, or GitHub Release.
