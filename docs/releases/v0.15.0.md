# AtomLearn 0.15.0 Release Notes

Status: stable candidate. Stable publication exists only after the immutable
`v0.15.0` tag, complete runtime matrix, Ed25519-signed manifest, and GitHub
Release assets are all published and independently verifiable.

## Scope

AtomLearn 0.15.0 completes the v0.15 product-readiness program and adds the
public open-source foundation. It is the first release line that combines the
strict single-Atom learning loop with unified intake, revision-bound RAG,
research and exam automation, session adaptation, bounded self-evolution,
adaptive review, structured figure/table evidence, and a UI-neutral knowledge
graph contract.

If publication succeeds, the signed stable runtime will include only the
dependency-light `base` profile. Automatic pypdfium2/Tesseract OCR, local
Sentence Transformers, USearch HNSW, and local cross-encoder execution remain
explicit developer/source extras. Their implementation in the repository is not
a stable-delivery claim.
The bundled Release Manager is version `0.3.0`; `v0.14.2`'s Manager `0.2.0`
remains an immutable earlier artifact rather than being republished with new
contents.

## Major delivery changes

- Windows state transactions use short, target-independent exclusive temporary
  filenames so deeply nested course and Manager paths retain atomic replacement
  without inheriting the full destination filename twice. Runtime creation also
  bootstraps only CPython's bundled pip wheel, avoiding the unnecessary legacy
  setuptools test tree that can exceed Windows path limits on Python 3.10/3.11.
- One source, outline, topic, or mixed Goal Contract now drives coverage,
  correction, planning, diagnostics, and exact-revision readiness.
- Evidence v3 binds task form, scorer identity, evidence family, timing window,
  retention, and transfer feasibility without reinterpreting historical v2
  records.
- RAG adds held-out multilingual, domain-shift, hard-negative, structured,
  OCR/layout, and adversarial-grounding profiles with explicit retrieval,
  reranking, locator, and unsupported-claim failure attribution.
- Exam processing adds review-only hybrid knowledge mapping, official and
  empirical difficulty provenance, item families, and independently revisioned
  capacity-aware schedules.
- Research reading adds provenance-cached provider adapters, DOI/title
  deduplication, citation integrity, claim-level cross-paper synthesis, and
  current-source locators.
- Document IR retains structured table spans and figure/table geometry, caption,
  crop hash, extraction method, confidence, and review status. OCR/vision
  numeric observations remain proposals until reviewed or reproducible.
- `graph-view-v1` exposes typed prerequisite, containment, scheduled, optional,
  citation, and semantic edges to read-only clients without transferring
  canonical-state ownership.
- Apache-2.0 licensing, third-party notices, community policies, bilingual
  documentation, privacy/history scanning, CodeQL, and wheel-license checks
  prepare the repository for public contribution.

## Compatibility and upgrade

- Core 0.15.0 reads the existing v1 workspace namespaces, Evidence v1/v2/v3,
  and measurement-bank v1/v2 under the declared conservative migration rules.
- Upgrade planning remains read-only until the user confirms an exact signed
  Manager operation. Existing learner state is copied and validated rather than
  rewritten in place.
- Self-evolution, global personalization, strategy experiments, Capsule export,
  and release-manager mutation remain independently default-off.
- The active Ed25519 trust key remains `release-2026-08` with fingerprint
  `sha256:19e079c2aece68bae50eac9af779e3e0bb74e04edebaf43a2ad3d08e71dbb222`.

## Verification and claim boundaries

Stable publication requires the complete Windows/Linux Python 3.10–3.13 base
matrix, the named scale-RAG gate, fast and integration suites, migration and
compatibility fixtures, property tests, update fault injection, privacy attacks,
the repository/history gate, target-platform runtime smoke receipts, and signed
artifact verification.

These are engineering and harness-contract results. AtomLearn 0.15.0 does not
claim a causal human learning-gain effect. Such a claim requires a separate,
consented, preregistered study and cannot be inferred from repository tests,
retrieval metrics, scorer calibration, local strategy experiments, or usage
telemetry.

## Installation

Verify the Manager wheel and public trust fingerprint independently, then use:

```powershell
python -m pip install "https://github.com/panjose/Atom-Learn/releases/download/v0.15.0/atomlearn_manager-0.3.0-py3-none-any.whl"
atomlearn-manager bootstrap plan 0.15.0 --expected-fingerprint sha256:19e079c2aece68bae50eac9af779e3e0bb74e04edebaf43a2ad3d08e71dbb222
atomlearn-manager bootstrap apply 0.15.0 --expected-fingerprint sha256:19e079c2aece68bae50eac9af779e3e0bb74e04edebaf43a2ad3d08e71dbb222 --confirmed
```
