# AtomLearn Manager

`atomlearn-manager` is the independently installable signed release manager for
AtomLearn Core. It verifies immutable manifests, installs versioned Core and
runtime profiles side by side, and supports recovery and paired rollback without
allowing a learning session to update itself.

See the repository [Release Manager documentation](../atom-learn/references/RELEASE_MANAGER.md)
for the trust, bootstrap, profile, migration, and recovery contracts.
